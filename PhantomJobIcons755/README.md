# Patch 7.55 Phantom Job Icons

The transparent, blue, and sprite files are direct extractions from the installed FFXIV game data.
The black variant uses the exact transparent symbol composited over a frame reconstructed
from the existing Phantom Job black-icon set so it matches the established assets.

Each job folder contains:

- `transparent.png`: exact 56x56 crop from `MKDSupportJobIcon_hr1.tex`
- `blue.png`: exact 48x64 HR status icon texture
- `black.png`: matching 56x56 generated black-background icon
- `sprite.png`: exact 80x116 crop from `MKDSupportJob_hr1.tex`
- `sources.json`: row IDs, icon IDs, and exact source coordinates
